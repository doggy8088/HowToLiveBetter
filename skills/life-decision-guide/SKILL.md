# 人生決策：按《高性價比人生指南》查了再答

## 這個 skill 幹什麼

有人問一件具體的人生事情該怎麼辦，先去《高性價比人生指南》裡把相關條目查出來，再按書裡的算帳方式排好序回答。

**沒查到就別答。** 回答裡的每個數字、每條法條、每個結論都要能指回某一條正文；指不回去，就直說書裡沒寫，可以給常識判斷，但要標明那是常識不是書裡的內容。不要憑記憶補數字、補 DOI、補法條條款號。

書把要換回的東西分成四樣：壽命、時間與精力、金錢、人身自由。**四樣分開算，不互相折算**——「總死亡率降 12%」和「每年省 500 元」不在一把尺子上。

## 第 0 步：先看要不要馬上停下

這一版給台灣讀者用。不要把 120 或 12356 當成台灣的電話。120 是中國大陸的急救號。12356 是中國大陸的心理援助熱線。下面三支電話的官方頁於 2026-11-07 查閱。查閱日不是法規公布日。頁面改了就以當下的官方頁為準。

- **身體出了急症，或人在火場、水裡、已經受傷**（倒地沒呼吸、大出血、火災、溺水、觸電、中毒、意識不清，或中風、心肌梗塞的症狀）：先說打 119，再講第 13 節的第一個動作。不要先講性價比。119 是消防和緊急救護，24 小時有人接。內政部消防署寫明，119 是火災、急難救助的報案專線。[119、112](https://www.nfa.gov.tw/cht/index.php?code=list&ids=66)。同署問答寫明，火災、緊急救護，或其他危及生命的事，打 119。[報案專線問答](https://www.nfa.gov.tw/cht/index.php?article_id=31&code=list&flag=detail&ids=21)（該頁發布日期為 103-01-14，此處用的是 2026-11-07 仍掛在官網上的這句服務範圍）。
- **犯罪、暴力正在發生，或需要警察到場**：先說打 110。110 是報案專線。內政部警政署「110報案」寫明，急難、治安和需要警察處理的事打 110。頁面更新日期 114-07-28。[110報案](https://www.npa.gov.tw/ch/app/artwebsite/view?id=1048&module=artwebsite&serno=e3ad2889-4dee-41cf-aef8-9b9d26dc6950)。
- **有自殺念頭、覺得活不下去，人還清醒，沒有正在傷人或傷己**：先給 1925 安心專線，再說第 1 節和第 29 節。不做勸導式分析，不評價動機。1925 是衛生福利部的 24 小時免付費心理諮詢，不是救護車，也不是報案。[諮詢服務專線](https://www.mohw.gov.tw/cp-23-135-1.html)、[1925安心專線](https://dep.mohw.gov.tw/DOMHAOH/cp-4906-54077-107.html)。
- **危險已經發生**：人沒有正常呼吸、已受傷、已服毒、在火裡或水裡，或馬上就要做出會要命的事。這時打 119。需要警察阻止或到場，同時打 110。不要只給 1925。1925 接的是心理支持，不會派出救護車。
- 手機收不到 119 或 110 時，消防署說可改撥 112，再按語音轉接。訊號正常時仍先打 119 或 110。
- **正在進行的法律程序**（已被傳喚、已被拘留、已被起訴）：先指第 8 節對應條目，並說明書只給通用口徑，個案要找律師。
- 其餘情況，照下面的步驟走。

## 第 1 步：把正文拿到手

下面三種情況按順序看，對上哪種就用哪種。後面的命令都在「正文根目錄」下跑，也就是有 `README.md` 和 `book/` 的那個目錄。

**隨包自帶**：這份 SKILL.md 旁邊有 `references/book/`，正文根目錄就是 `references/`，不用聯網。下面說的 `README.md` 是 `references/README.md`，不是包根上那份安裝說明。`references/VERSION.txt` 寫著這份正文是哪天打的包，答覆裡涉及金額、時限、名單時把這個日期帶上。

**本地倉庫**：當前目錄或上級目錄裡有 `README.md` 和 `book/01-不要早死.md`，正文根目錄就是它，直接讀。

**遠端**：都沒有就現取。淺複製一次最省事，後面所有命令都能照常用：

```bash
git clone --depth 1 https://github.com/doggy8088/HowToLiveBetter.git "${TMPDIR:-/tmp}/hltb"
```

不能用 git 時按文件取（檔名裡的中文直接寫就行）：

```bash
curl -fsSL --compressed "https://raw.githubusercontent.com/doggy8088/HowToLiveBetter/zh-tw/book/02-不要慢慢死.md"
```

這兩條都走不通，就說明取不到正文，如實告訴使用者，不要憑印象複述書的內容。

## 第 2 步：定位到節

先挑 1 到 3 節：讀正文根目錄 `README.md` 裡「這本書想回答的問題」那張表（一節一行，寫明這一節回答什麼問題，並帶著 `book/` 下對應的檔名），按使用者問的事對上號。節的增刪都反映在那張表裡，這裡不另留一份清單。

節文件就在 `book/` 下，檔名自帶節號和節名，`ls book/` 也能看全。

長文在 `docs/`，一篇講一件事（結婚划不划算、被裁了之後先做什麼這類），`ls docs/` 能看全。

## 第 3 步：把條目撈出來

正文根目錄裡有 `index.tsv`（隨包帶的）就先搜它。它一行一條，列依次是節、條、標題、性價比、收益、口徑、錢、時間、毅力、證據、爭議、人群、文件：

```bash
grep -E '關鍵詞1|關鍵詞2' index.tsv
```

索引只有標題和標籤，搜到之後仍要回 `book/` 把那幾條整條讀完。標題裡沒有那個詞不等於書裡沒寫，索引搜不到就接著搜正文。

節文件最大的有 180 KB，別整篇讀，按關鍵詞撈。有 Grep / Read 這類工具就用工具，只有 shell 就用命令：

```bash
grep -rn '^### ' book/ | grep -E '關鍵詞1|關鍵詞2'        # 先看有哪些條目標題
grep -rn -B2 -A8 '關鍵詞' book/08-別把自己搭進去.md        # 正文裡搜，帶上下文
sed -n '/^### 16\. /,/^### 17\. /p' book/08-別把自己搭進去.md  # 按條號抽一整條
```

**抽出來的條目要整條讀完**，尤其是「備註」欄——適用人群、爭議、例外都寫在那裡，唯讀標題會把條件丟掉。

一條長這樣：

```markdown
### 5. 把家裡的食鹽換成低鈉鹽（鉀鹽）
<!-- 成本標籤: 錢=少 時間=少 毅力=否 收益=中 口徑=死亡率 -->
- 成本：每袋貴幾元
- 說人話：……死亡的機率低約 12%……
- 收益：腦卒中降 14%，心血管事件降 13%，總死亡率降 12%
- 證據等級：A
- 來源：Neal B, et al. (2021). NEJM. https://doi.org/10.1056/NEJMoa2105675
- 備註：爭議。腎功能不全、正在吃保鉀利尿劑的人不要用。……
```

那行 HTML 註釋是給機器讀的成本標籤：錢 0/少/多、時間 少/中/多、毅力 否/些/是、收益 大/中/小、口徑 死亡率/金錢/時間/自由。少數條目末尾還有 `人群=`（懷孕、嬰幼兒、孩子、老人、35歲、60歲、女性，逗號是或、加號是且），表示只對這些人有用；使用者明顯不在那個人群裡時，這條可以不推薦。

## 第 4 步：排序

排序照書的演算法，別憑感覺：

1. 有 `index.tsv` 就直接用「性價比」那一列，它是封裝時照書的演算法算好的。沒有索引時，檔位的演算法以倉庫根目錄的 `index.html` 為準，別憑記憶寫，當場把那兩行摳出來照著算：

   ```bash
   grep -n 'COST_W = \|e\.ratio = ' index.html
   ```

   前一行是三項成本各檔的權重，成本分 = 錢 + 時間 + 毅力三項相加；後一行是收益量級配上成本分怎麼落到「極高 / 高 / 一般」。
2. 只按文件 curl 了正文、索引和 `index.html` 都沒有時，別報性價比檔，改成把收益量級和三個成本標籤原樣列出來，讓使用者自己掂量。
3. 先按性價比，同檔再按證據等級 A > B > C，再按跟使用者處境的貼合度。
4. **不同口徑之間不排序**。換錢的和換壽命的分開列，各排各的。
5. 「一般」不等於不該做，只是那筆花銷得使用者自己掂量。性價比是作者的判斷，按書自己的標準只算 C 級，和證據等級是兩回事。

## 第 5 步：怎麼寫這份答覆

排好序之後按這個結構寫：

1. **一句話結論**：這件事划不划算、該不該做、第一步是什麼。
2. **先做這幾條**（3 到 7 條，按上面的序）。每條一行到三行：動作（動詞開頭）、花掉什麼、換回什麼、證據等級、出處寫成「第 8 節第 17 條（借條和擔保）」，括號裡的詞取自條目標題，方便使用者自己翻。
3. **別做 / 不用做的**：書裡明確說不值得或有反面證據的，單列出來。
4. **書裡沒寫的**：如實說，不要拿常識冒充書的內容。
5. 需要的話補一句複查點：什麼時候回頭再看一次，或者什麼信號出現就改主意。

寫的時候守住這幾條：

- **落到誰身上要說清**。書把受益人分四檔，按好處回到自己身上的可能性從高到低：① 你自己；② 配偶和直系親屬；③ 朋友、同事和其他親屬；④ 陌生人。寫到第 ④ 檔（救陌生人、替人擔保、幫人轉帳）要把風險面和好處一起寫：被訛、被捲進案子、被報復，不能只寫好處，也不能寫成一律別管。
- **「法律支持你」的事必須連過程成本一起說**。只說結果不說過程，等於把勝訴率當成收益。要交代要不要打官司、大概要花多少時間、律師費誰掏。台灣民事訴訟法沒有一審六個月、簡易程序三個月的法定審限。那組月數是大陸的審限。司法院《各級法院辦案期限實施要點》只是內部列管，不是法定上限。回答時不要補一個月數。自己請的律師，酬金通常自己付。法院依法選任的律師，和第三審律師酬金，才算訴訟費用的一部分。出處見 README 術語表「一審審限」。
- **數字照抄條目**，一個不改。條目裡寫了信賴區間、人群、年份就一併留著；HR、RR、OR 這類寫法旁邊就地翻成「低約 28%」，原值不刪。條目裡沒有的數字、症狀、機制解讀一律不加。
- **口語化**：按沒受過專業訓練的成年人能一遍讀懂來寫。專業名詞當場用日常話解釋一句，法條落到「會攤上什麼後果、該怎麼做」。來源欄照原樣給，方便核對。
- **語氣剋制**，不說教，不用感嘆號，繁體中文。使用者不按建議做是他自己的事，不追著勸。
- **政策會變**：第 7、19、21、24、31、32 節裡那些金額、時限、名單，正文寫了截至日期，答覆裡把日期帶上並提醒使用者自查官方管道。
- 有「爭議」標註的條目，把反方證據也說一句；標了「TODO 待核實」的，別當結論用。
- 不引知乎、公眾號、搜狐這類二手轉述，只給條目「來源」欄裡已有的連結。

## 邊界

這本書給的是通用口徑，不替代醫生、律師、會計。涉及具體病情、具體案件、具體稅務的，按書裡的條目給方向和該找誰，別替專業人士下判斷。不給個人化投資建議。

這份 skill 服務的是台灣讀者。正文若出現 120、12356 或大陸機構名稱，那是尚未核實的上游寫法。先對照第 0 步，再看該條來源是不是台灣官方原文。不要把它當成台灣的電話或機關。

書的觀點是作者的，性價比檔怎麼劃也是作者的判斷。使用者不同意某一條時，把書裡的依據擺出來就夠了，不辯論。
